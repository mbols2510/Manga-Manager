# Manga Manager 3.3.2

Fix found by checking the Kavita calls against a real server (Kavita 0.9.1.4, read-only).

## Fixed

- **Marking a chapter read.** Both `KavitaClient.mark_chapter_read` (read-progress carry-over)
  and the Double Chapters tool called `POST /api/reader/mark-chapter-read`, which Kavita does
  not have. They now call `POST /api/Reader/mark-multiple-read` with
  `{"seriesId": ..., "volumeIds": [], "chapterIds": [<id>]}`.

## Verified against a real server (read-only)

Token accepted and admin; `GET /api/Series/volumes` (volumes[].chapters[] with id, volumeId,
pages, pagesRead, files[].filePath); `POST /api/Series/all-v2`; `GET /api/Server/is-task-running`
(JSON `false`); `/api/Server/activity` is 404 (handled); version 0.9.1.4.
