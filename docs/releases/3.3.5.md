# Manga Manager 3.3.5

## Fixed

- **Read progress was lost when a file with the same name replaced a chapter.** The carry-over of read
  progress only ran when the new file had a different name. When the new file overwrote the old one in
  place, Kavita kept the old pages-read count, so a fully read chapter whose new file had more pages
  showed as half read. The progress of the chapter is now remembered before the overwrite and set again
  after the Kavita rescan: fully read stays fully read, partly read is scaled to the new page count,
  unread is left alone. Nothing is changed when the page count is the same. This applies to normal runs
  and to "Move chapters" for an alias.
- Chapters that were already overwritten before this version are not corrected; mark them read in Kavita.
