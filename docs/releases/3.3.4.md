# Manga Manager 3.3.4

## Fixed

- **"Move chapters" did not replace official chapters.** When an alias is set on an official, uncensored
  or official uncensored title, moving its chapters into the Kavita series only moved the files, so the
  same chapter from a lower-ranked source stayed next to it and had to be fixed by hand on the Doubles
  tab. It now applies the same rule as a normal run: the preferred chapter replaces the old one (the old
  file goes to the shared trash and can be restored), read progress is carried over, and the rank of the
  moved files is recorded. The preview shows how many chapters would be replaced.
- The existing limits still apply: a preferred file with fewer than `src.min_page_pct` of the old file's
  pages is not used (both are kept), and chapters whose numbers can't be matched are not replaced.
