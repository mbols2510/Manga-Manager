# Manga Manager 3.3.0

Released 14 November 2026. Fixes and features for GitHub issues #5 to #9.

## Kavita scan coordination (#7)

- Scan requests now wait while Kavita reports a running or queued scan. The
  check covers ScanSeries, ScanLibrary, ScanLibraries and ScanFolder, uses
  `/api/Server/activity` on versions that have it, and treats API errors as an
  unknown state that is retried after a delay. This needs an admin Kavita user.
- Duplicate scan requests for the same series are combined.
- New option **`kavita.scan_bulk_enabled`** (off by default): when more than
  **`kavita.scan_bulk_threshold`** (default 5) distinct series of one library were
  updated in a run, one library scan replaces their individual scans. Exactly the
  threshold or fewer still scan individually. Libraries are evaluated separately
  and processed from smallest to largest.
- Also new: `kavita.scan_poll_interval` (default 15 s) and `kavita.scan_wait_timeout`
  (default 1800 s; after this the scan is submitted anyway so a run never stalls).
- The log states when a scan is waiting and when a library scan replaces series scans.
- Scans are now always submitted smallest library first.

## Read progress for replaced chapters (#6)

When an official or preferred-source chapter replaces an existing one, the read
progress of the old chapter is carried over to the new one (fully read stays fully
read, partial progress is scaled to the new page count, unread stays unread).
Kavita errors only log a warning and never stop the replacement.

## Official manga added to aliases (#8)

Manga in the Suwayomi category set by **`suwayomi.official_library`** (default
`ADULT_OFFICIAL`, empty turns it off) are added to the aliases automatically with an
empty Kavita source. Until you fill in the Kavita source, the manga is not moved.

## Alias menu overhaul (#9)

The alias list is now a grid of cover cards with a status badge, filter tabs
(All / Missing alias / Missing Kavita source / Done) with counts, and search.

## Install app button removed (#5)

The non-functional "Install app" button is gone. The PWA itself is unchanged.

## Known limitations

- The Kavita endpoints used for read progress and `/api/Server/activity` follow
  Kavita's API as documented; they were not tried against a live Kavita. Check one
  chapter replacement after upgrading.
- Matching a replaced chapter's progress is by file name within the series.
- Deleting an auto-added alias while the manga stays in the official category
  re-adds it on the next run.

## Verification

All 261 automated tests pass against a PostgreSQL 16 database (17 environment-dependent
tests skip). The alias menu's layout was not checked in a browser.

## Upgrade

Use `ghcr.io/mbols2510/manga-manager:3.3.0` (Linux amd64/arm64), or the `latest`
channel. Reuse your existing database, configuration and mounted folders. No
destructive database migration is required.
