# Manga Manager 3.3.3

## Fixed

- **Aliases page listed every manga.** It showed a "No alias" card for every Suwayomi manga without an
  alias, not only for the official category. It now adds those cards only for manga in
  `suwayomi.official_library` (default `ADULT_OFFICIAL`), the same category that is auto-added to the
  aliases. Existing aliases still show. With `official_library: ""` the page lists all manga as before.
  The auto-add itself was already correct and is unchanged; nothing is stored for other categories.

## Not tested

The Aliases page was not checked in a browser; the change is covered by unit tests only (the Postgres
tests ran in CI).
